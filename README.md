# Astro Media Voice Console — Render / Python

A small Flask app for uploading audio or video, previewing the original file, converting its audio track to MP3, and playing the selected audio on **incoming calls to your own configured Twilio number**. This project does not place outbound calls and does not use the third-party `api-modifyxhub.tech/live-call` endpoint.

## Included

- Password-protected dashboard with CSRF tokens.
- MP3, WAV, M4A, AAC, OGG, FLAC, MP4, WebM, MOV upload.
- 25 MB upload limit; up to 2 minutes of audio or 1 minute of video.
- `ffprobe` validation and FFmpeg normalization to MP3.
- Original-file and normalized-MP3 preview players.
- Select the audio used for future inbound calls.
- `/voice` inbound voice webhook that validates `X-Twilio-Signature` and replies with TwiML `<Play>`.
- Signed, expiring media URLs so media is not served at a guessable public path.
- Optional S3-compatible object storage for data that must survive Render deploys/restarts.
- `/health` health endpoint.

## Deploy to Render

1. Extract this ZIP and push the **contents** of this folder to a GitHub repository (the `Dockerfile` and `render.yaml` should be at the repository root).
2. In Render, choose **New + → Blueprint**, connect the repository and apply `render.yaml`. The Docker image installs FFmpeg and Python dependencies.
3. In the environment variables prompted by Render, set:
   - `ADMIN_PASSWORD`: a strong, unique dashboard password.
   - `PUBLIC_BASE_URL`: the exact HTTPS base URL Render assigns, with no trailing slash, e.g. `https://your-service.onrender.com`.
   - `TWILIO_AUTH_TOKEN`: the current Auth Token from your own Twilio account. Do not use an API Key Secret here.
   - `SECRET_KEY` and `MEDIA_SIGNING_SECRET` are generated by the Blueprint. Keep them private.
4. Open `https://your-service.onrender.com/`, log in with `ADMIN_PASSWORD`, upload a file, and preview it.
5. In the Twilio Console, configure **your own phone number's incoming Voice webhook** as `https://your-service.onrender.com/voice` using HTTP POST. Keep the exact same URL in the provider console and `PUBLIC_BASE_URL` setting. If using a custom domain, set `PUBLIC_BASE_URL` to that domain instead.
6. Call your own provider number from a test phone with consent to verify playback. The `/voice` route rejects requests without a valid Twilio signature.

## Important storage note for Render Free

Render's default filesystem is ephemeral, so locally stored media/index files can disappear on restart or redeploy. This is a platform limitation, not a Python bug. For durable files, either attach a Render persistent disk on a plan that supports it and set `DATA_DIR` to its mount path, or configure private S3-compatible object storage using all required variables below. The app selects S3 storage only when bucket, access key, and secret are all supplied.

Optional environment variables for S3-compatible storage:

- `S3_BUCKET`
- `S3_ACCESS_KEY_ID`
- `S3_SECRET_ACCESS_KEY`
- `S3_ENDPOINT_URL` (optional for AWS S3; required by many compatible providers)
- `S3_REGION` (defaults to `auto` when an endpoint is supplied, otherwise `us-east-1`)
- `S3_PREFIX` (default `media-voice`)

Use a **private bucket** and credentials scoped to that bucket. Media is proxied through the app; the bucket itself does not need public access. Do not commit credentials into GitHub or this project.

## Local run

Requires Python 3.12+, FFmpeg and ffprobe on PATH.

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

Set environment variables from `.env.example` in your shell (or your IDE's run configuration), then run:

```bash
python app.py
```

Open `http://127.0.0.1:10000/`. Twilio webhook validation needs a publicly reachable HTTPS URL; the local dashboard and upload can be tested without configuring the webhook.

## Supported flow / limits

- Uploading/selecting media does not place any calls.
- The playback webhook only handles inbound calls routed by your own provider to `/voice`.
- The full audio track is played once; it is not truncated to a short preview.
- Video files must contain an audio track; the audio is extracted to MP3 for voice playback.
- Twilio may reject files it cannot retrieve. The signed audio URL is HTTPS and expires after `MEDIA_LINK_TTL_SECONDS` (default 6 hours).
- If the provider webhook fails signature validation, make sure `TWILIO_AUTH_TOKEN` is the account Auth Token and `PUBLIC_BASE_URL` is exactly the URL configured in the provider console.
